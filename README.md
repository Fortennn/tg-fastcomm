# ⚡ TG FastCommenter (Glassmorphism Desktop App)

Стильное десктопное приложение для Telegram с современным дизайном в стиле **Glassmorphism** (эффект матового полупрозрачного стекла, неоновые сферы, живая лента событий).

Бот работает через ваш личный Telegram-аккаунт, отслеживает новые посты в каналах и автоматически оставляет комментарий (по умолчанию `"беру"`), когда пост содержит заданные ключевые слова.

---

## 🎨 Особенности интерфейса (UI)
- **Glassmorphism Design**: эффект матового стекла (`backdrop-filter: blur`), мягкое неоновое свечение, плавающие градиентные сферы и глубокая темная тема.
- **Интерактивная авторизация**: вход в Telegram через модальное окно прямо в приложении (ввод номера → код из Telegram → 2FA пароль, если включен). Консоль больше не нужна!
- **Живая лента событий (Activity Feed)**: в реальном времени отображает найденные посты, сработавшие триггеры, отправленные комментарии и ошибки с цветными бейджами и фильтрами.
- **Статистика в реальном времени**: счетчики проверенных постов, сработавших триггеров и отправленных комментариев.
- **Удобное управление**: быстрая кнопка запуска/остановки, пресеты ключевых слов (chips) и ползунок регулировки задержки отправки.

## 🚀 Быстрый запуск

### Вариант 1: Запуск графического приложения (UI)
Дважды кликните по файлу **`run_app.bat`** (или выполните `python app.py`).
Откроется нативное окно приложения с интерфейсом Glassmorphism.

### Вариант 2: Запуск в режиме консоли
Если нужно запустить бота без интерфейса, запустите **`run.bat`** (или `python main.py`).

## ⚙️ Настройка при первом запуске

1. **Получите API ключи**:
   - Откройте [https://my.telegram.org](https://my.telegram.org).
   - Войдите по номеру телефона.
   - Перейдите в раздел **API development tools** и создайте приложение (любое имя).
   - Скопируйте **`api_id`** и **`api_hash`**.

2. **Заполните параметры в приложении**:
   - Вставьте `API ID` и `API HASH` в карточку настроек.
   - Укажите каналы для отслеживания (или оставьте пустым для всех).
   - Задайте ключевые слова (например: `раздача, отдам, конкурс`).
   - Нажмите **"Сохранить настройки"**.

3. **Авторизуйтесь**:
   - Нажмите кнопку **"Войти"** в правом верхнем углу.
   - Введите свой номер телефона, затем код из Telegram.
   - После входа нажмите большую кнопку **"Запустить мониторинг"**!
